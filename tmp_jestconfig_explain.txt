Jest とは

Jest は JavaScript / TypeScript のテストフレームワークです。書いたコードが期待通りに動
くかを自動で確認するためのツールです。

例えばこういうテストが書けます：
it('1 + 1 は 2 になる', () => {
expect(1 + 1).toBe(2) // パスする
})

it('ログイン関数が正しく動く', () => {
expect(login('user', 'pass')).toBe(true) // パスする/しないで検知
})

---
jest.config.ts の役割

Jest の動作設定をまとめたファイルです。各項目を説明します。

// Next.js 用の Jest 設定を生成するヘルパー
// TypeScript や CSS Modules の変換を自動でやってくれる
const createJestConfig = nextJest({ dir: './' })

// テスト環境をブラウザ相当にする（document や window が使える）
testEnvironment: 'jsdom',

// テスト実行前に jest.setup.ts を読み込む
setupFilesAfterEnv: ['<rootDir>/jest.setup.ts'],

// @/components/... → src/components/... に解決する（tsconfig の paths と合わせる）
moduleNameMapper: { '^@/(.*)$': '<rootDir>/src/$1' },

// カバレッジ（テストがコードのどこをカバーしているか）の計測方法
coverageProvider: 'v8',

// カバレッジの対象ファイルを src/ 以下の ts/tsx に限定
collectCoverageFrom: ['src/**/*.{ts,tsx}', '!src/**/*.d.ts'],

カバレッジとは？

テストがソースコードのどの部分を実行したかを示す指標です。

---
具体例

例えばこんな関数があるとします：

function getGrade(score: number) {
if (score >= 80) {
    return 'A' // ← ①
} else if (score >= 60) {
    return 'B' // ← ②
} else {
    return 'C' // ← ③
}
}

テストがこれだけだと：
it('80点以上はA', () => {
expect(getGrade(90)).toBe('A') // ①しか通らない
})

カバレッジは33%（3つの分岐のうち1つしかテストできていない）になります。

// 3つ全部テストすると100%
it('80点以上はA', () => expect(getGrade(90)).toBe('A'))
it('60点以上はB', () => expect(getGrade(70)).toBe('B'))
it('60点未満はC', () => expect(getGrade(50)).toBe('C'))

---
確認方法

npm run test:coverage

実行するとこんなレポートが出ます：

File         | % Stmts | % Branch | % Funcs | % Lines
-------------|---------|----------|---------|--------
getGrade.ts  |   100   |   100    |   100   |   100

---
カバレッジが高ければいいのか？

**必ずしもそうではありません。**100%を目指すより「重要なロジックがテストされているか」
の方が大切です。カバレッジはあくまで品質の目安の一つです。
