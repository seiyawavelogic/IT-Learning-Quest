# IT-Learning-Quest
## whats's this project? 
このリポジトリは IT学習のクエスト形式で進める学習教材です。<br>
学習の進捗管理や課題チャレンジを目的としています。<br>
<br>
## How to use?
- 1. このリポジトリをクローン<br>
- 2. dockerをインストール※済みであればスキップ可能<br>
- 3. ```docker compose up -d```によってプロジェクトが立ち上がる<br>
